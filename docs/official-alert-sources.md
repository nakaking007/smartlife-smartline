# Official Alert Sources

แนวทางเชื่อมข้อมูลราชการสำหรับ SmartLife Scheduler & Alert

## แผ่นดินไหว

- แหล่งข้อมูลหลัก: กรมอุตุนิยมวิทยา (TMD) / Earthquake Observation Division
- ช่องทางที่ควรเชื่อม: RSS Earthquake, TMD Open Data หรือ API ที่ได้รับสิทธิ์ใช้งาน
- การส่ง LINE: ส่งอัตโนมัติเมื่อผ่านเกณฑ์ความรุนแรงและอยู่ใกล้พื้นที่ผู้ใช้

## สึนามิ

- แหล่งข้อมูลหลัก: กรมอุตุนิยมวิทยา, ศูนย์เตือนภัยพิบัติแห่งชาติ, ปภ.
- ช่องทางเสริม: PTWC, USGS, GDACS สำหรับเฝ้าระวังเบื้องต้น
- การส่ง LINE: ส่งเป็น `critical` เมื่อมีประกาศทางการ หรือส่งเป็น `watch` หากเป็นข้อมูลเสริมที่ต้องติดตาม

## กติกาความปลอดภัย

- ข้อมูลจากหน่วยงานราชการโดยตรงสามารถส่งอัตโนมัติได้
- ข้อมูลจากแหล่งเสริมให้ใช้คำว่า "เฝ้าระวัง" และควรรอการยืนยันก่อนยกระดับ
- ข้อความต้องมีคำแนะนำที่ทำได้ทันที เช่น ออกจากชายฝั่ง ไปที่สูง หรืออยู่ห่างจากกระจก
- ต้องเก็บ `source` และ `sourceUrl` ทุกครั้ง เพื่อให้ผู้ใช้ตรวจสอบแหล่งที่มาได้
